# HomeGymLog support

HomeGymLog builds a phased strength program (Foundation, Build, Peak, Deload) from five onboarding answers and then logs every set you lift.

## Equipment it is built for

- Adjustable dumbbells from 5 to 52.5 lb in 2.5 lb steps
- An adjustable bench (flat and incline)
- A Marcy MWM-8147 home gym with a 150 lb weight stack

Every exercise, weight and progression in the app fits that equipment.

## Back up and restore

Open Settings in the app. **Export backup…** writes a JSON file you can save to Files, AirDrop or mail to yourself. **Restore from backup…** opens a file picker; restoring replaces everything on the phone with the backup after a confirmation.

## Reminder and Lock Screen timer

In Settings, **Daily reminder** schedules a local notification on each training day at the time you pick. **Lock Screen timer** shows the rest countdown as a Live Activity on the Lock Screen and in the Dynamic Island. Both can be turned off at any time; iOS Settings controls the permissions.
